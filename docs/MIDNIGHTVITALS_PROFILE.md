# RWAz MidnightVitals Profile

The canonical protocol is maintained at
[`../../DIDzMonolith-docs/standards/MIDNIGHTVITALS_PROTOCOL.md`](../../DIDzMonolith-docs/standards/MIDNIGHTVITALS_PROTOCOL.md).

The RWAz profile should verify object registration, ownership proof,
encumbrance, provenance continuity, governed transfer, and retirement without
exposing private ownership data. This file is a pointer and profile boundary,
not a competing protocol specification.
