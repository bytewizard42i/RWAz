# Submission Instructions — RWAz Protocol

Procedures verified against primary sources July 27, 2026. The full
generic playbook lives in
`didz-kernel/FORMAL_SPECS_W3C_DIF/SUBMISSION_INSTRUCTIONS.md`; this file
covers only what is RWAz-specific.

## Step 0 — Provenance first

1. Public repo (`bytewizard42i/RWAz`) — John's call.
2. Git tag + GitHub Release (`rwaz-spec-v0.1-draft`).
3. Internet Archive snapshot; optionally Zenodo DOI.

## Step 0.5 — IP gate

Standard: W3C CLA royalty-free commitments / DIF open-source outputs.
If the encumbrance-blocked-transfer or provenance-head mechanism might
be patented, provisional filing BEFORE contributing. John's decision.

## Step 1 — DIF (primary)

Venue: **Claims & Credentials WG** (credential schemas over non-person
subjects; the encumbrance pattern). Join DIF; send
`letters/LETTER_DIF.md`; propose a Pre-Draft work item. Coordinate with
the DIDz Protocol + AgenticDID submissions — RWAz is the object pillar
of that stack.

## Step 2 — W3C CCG (secondary)

Join CCG (free, CLA); send `letters/LETTER_W3C.md` to
`public-credentials@w3.org`, subject `[rwaz] Introduction: permanent
object identity with ownership as credentials`.

## Positioning cautions

- Always lead with "NOT an NFT standard" — reviewers will assume
  token semantics otherwise.
- Repeat the no-legal-effect caveat in every venue; regulators and
  title-industry readers must never hear a legal claim we don't make.
- Fractionalization/tokenization is v0.2+ roadmap; do not let
  discussion drift there before the identity/credential core is
  reviewed.
